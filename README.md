A Python-based computer vision tool that lets you control your media playback and volume using intuitive hand gestures!

## 🚀 Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saumojyoti-Shiv/Gesture-Controlled-Media-Player-.git
   cd Gesture-Controlled-Media-Player-
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the script:**
   ```bash
   python "Gesture Controlled Media Player.py"
   ```
   *(Press 'q' in the window to quit at any time)*

## 🎮 Gesture Guide

Control your media effortlessly with these gestures:

- 🤏 **Pinch (Left Hand):** Volume Control (distance between thumb and index finger)
- ☝️ **1 Finger (Right Hand):** Next Track (Forward)
- ✌️ **2 Fingers (Right Hand):** Previous Track (Backward)
- ✊ **Fist (Right Hand):** Play / Pause Media
- 🤜🤛 **Fists (Both Hands):** Mute / Unmute Volume
